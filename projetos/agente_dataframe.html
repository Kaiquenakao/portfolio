Agente de Consulta de DataFrame em Python

  • Visão Geral
  • Demonstração
  • Repositório

Este projeto apresenta um agente inteligente capaz de interpretar consultas em linguagem natural para manipulação de DataFrames do Pandas. Ele utiliza modelos da OpenAI para transformar comandos textuais em código Python seguro, executado em tempo real dentro de uma aplicação Streamlit. O objetivo é tornar a análise de dados mais simples, rápida e acessível, mesmo para usuários com pouca experiência em programação.

✨ Funcionalidades Principais

  • Carregamento de DataFrames a partir de arquivos CSV.
  • Interpretação de linguagem natural para operações em DataFrames.
  • Geração automática de código Python com base no pedido do usuário.
  • Execução segura do código gerado.
  • Visualização imediata dos resultados no Streamlit.

💡 Benefícios

  • Acelera o processo de exploração de dados.
  • Oferece uma interface intuitiva para manipular DataFrames.
  • Permite análises complexas mesmo sem conhecimento avançado em Python.
