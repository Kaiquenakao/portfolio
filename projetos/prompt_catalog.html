O Prompt Catalog é uma plataforma interna para gerenciamento, versionamento e monitoramento de prompts LLM em produção.

Times que usam LLMs em produtos enfrentam um problema recorrente: prompts vivem no código, em planilhas, ou na cabeça das pessoas. Quando algo dá errado em produção — uma resposta estranha, uma mudança de comportamento — não há rastreabilidade, não há histórico, não há rollback.

O Prompt Catalog resolve isso tratando prompts como artefatos de software:

  • Versionados: Cada alteração gera uma nova versão, as anteriores ficam preservadas.
  • Deployados: Um prompt só vai para produção após um deploy explícito.
  • Monitorados: Cada execução é logada com modelo, tokens, latência, variáveis e output.
  • Testáveis: Qualquer versão pode ser testada antes de ir para produção.
  • Auditáveis: O histórico separa execuções de playground (testes) de produção (API real).

Visão geral da arquitetura do Prompt Catalog.

O Prompt Catalog funciona através de uma interface que permite gerenciar o ciclo de vida completo de prompts em produção. Aqui está um resumo de como ele opera:

  • Criação e Versionamento: Crie prompts com variáveis dinâmicas e gerencie versões automaticamente. Cada edição gera uma nova versão sem sobrescrever as anteriores.
  • Deploy controlado: Prompts passam por um processo de deploy explícito antes de chegarem à produção, evitando alterações acidentais em ambiente real.
  • Playground de testes: Teste qualquer versão de um prompt com variáveis customizadas antes de promovê-la para produção.
  • Monitoramento de execuções: Todas as execuções são logadas com modelo utilizado, tokens consumidos, latência, variáveis de entrada e output gerado.
  • Auditoria: O histórico diferencia execuções de playground de execuções reais via API, garantindo rastreabilidade completa.
